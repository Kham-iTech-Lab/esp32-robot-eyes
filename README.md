# ESP32 หุ่นยนต์ตากะพริบ จอ OLED 👀🤖

ให้หุ่นยนต์มีหน้าตา ใช้จอ OLED 0.96" กับ ESP32 วาดตา 2 ข้าง กะพริบเอง มองซ้ายขวาแบบสุ่ม ดูมีชีวิต

จากคลิป **K iTech Review** (TikTok) · **Kham iTech Lab** (YouTube / Facebook)

## ของที่ใช้

| ชิ้น | หมายเหตุ |
|---|---|
| บอร์ด ESP32 | รุ่นไหนก็ได้ |
| จอ OLED 0.96" SSD1306 128x64 แบบ I2C (4 ขา) | หลักสิบบาท |
| สาย jumper 4 เส้น | |

## ต่อสาย

| OLED | ESP32 |
|---|---|
| VCC | 3V3 |
| GND | GND |
| SDA | GPIO 21 |
| SCL | GPIO 22 |

## ติดตั้ง

1. Arduino IDE ติดตั้งบอร์ด ESP32 (Boards Manager → esp32 by Espressif)
2. Library Manager ค้น **Adafruit SSD1306** กด Install ถ้าถามให้ติดตั้ง Adafruit GFX ด้วย กด **Install All**
3. เปิด `robot_eyes/robot_eyes.ino` แล้วอัปโหลด

## ปรับแต่ง

| ค่า | ทำอะไร |
|---|---|
| `EYE_W`, `EYE_H`, `EYE_R` | กว้าง สูง ความมนของตา |
| `LOOK_X`, `LOOK_Y` | มองไปได้ไกลแค่ไหน |
| `BLINK_MS` | กะพริบเร็ว/ช้า |
| `random(2000, 6000)` ใน `loop()` | ระยะห่างระหว่างการกะพริบ (มิลลิวินาที) |

## แก้ปัญหา

- **จอดำ / Serial ขึ้น "ไม่เจอจอ OLED"** — เช็คสาย SDA/SCL สลับกันไหม แล้วลองเปลี่ยน `OLED_ADDR` เป็น `0x3D`
- **จอ 1.3" (SH1106)** — ไลบรารีนี้ใช้ไม่ได้ ต้องเปลี่ยนเป็นไลบรารี Adafruit SH110X
- **จอเตี้ย 128x32** — เปลี่ยน `d(128, 64, ...)` เป็น `d(128, 32, ...)` แล้วตั้ง `EYE_H = 20`, `EYE_Y = 6`, `LOOK_Y = 4`
